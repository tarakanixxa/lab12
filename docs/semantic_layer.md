# Семантичний шар
Метрики описано в `semantic/metrics.yml`: загальний випуск, придатний випуск, частка браку, машинний час, час простою та середній машинний час на деталь. Кожна має визначення, формулу, одиницю, власника, джерела, обмеження й SQL.

`src/semantic_layer.py` реалізує `sql_for(metric_name)`, яка повертає SQL за ключем метрики. Скрипт виконує всі шість метрик і перевіряє узгодженість двох способів обчислення частки браку та придатного випуску: прямої агрегації та агрегації по верстатах із подальшим підсумовуванням. Метадані: власник — аналітична група «Метал-Деталь», дата перегляду — 2026-11-23, статус — draft-verified-on-synthetic-data.
